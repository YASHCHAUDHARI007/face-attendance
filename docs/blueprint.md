# **App Name**: SAMARTH FURNITURE AND MALL

## Core Features:

- User Registration: User interface for registering users by capturing a webcam photo and saving facial data.
- Attendance Check-in: User interface for marking attendance using webcam access for IN/OUT events.
- Geofence Verification: Browser based Geolocation API usage to ensure user is inside specified radius.
- Attendance Confirmation: UI showing the confirmation after successful attendance check.
- Attendance Log: Save the attendance data (name, date, time, location) in local storage, logging every IN/OUT event.
- Custom Shift Durations: Allow admin to set custom shift durations for each employee.
- Admin Page: Admin page to add/remove employee faces and view/download attendance logs and reports.
- Scan Page: Scan page with a button to mark IN/OUT events, capturing face and location.

## Style Guidelines:

- Primary color: Light lavender (#D1C4E9), chosen to evoke a sense of calm and reliability, which is critical in an attendance system.
- Background color: Almost-white lavender (#F3F0F7). Its very low saturation complements the primary color without causing distraction.
- Accent color: Soft purple (#B39DDB), providing subtle contrast and highlighting interactive elements without overwhelming the user.
- Body and headline font: 'Inter', a sans-serif font providing a clean and modern look for both headlines and body text.
